ERROR HANDLING & DEBUGGING
───────────────────────────────────────────────────────────────────────────────

CONSOLE LOGGING:
All important actions log with [v0] prefix:
   [v0] Signup attempt for: test@example.com
   [v0] User created: abc-123-def
   [v0] Login successful, redirecting...

ERROR MESSAGES (French):
   "Email ou mot de passe incorrect" - Wrong credentials
   "Le nom complet est requis" - Name missing
   "Les mots de passe ne correspondent pas" - Passwords don't match
   "Le mot de passe doit contenir au moins 6 caractères" - Too short
   "Vérifiez votre email..." - Email confirmation enabled
   "Impossible de créer le profil" - Profile creation failed

HOW TO DEBUG:
1. Check browser console (F12) for [v0] logs
2. Check Supabase SQL Editor for data
3. Check Supabase Auth logs for errors
4. Check TROUBLESHOOTING.md for solutions
5. Read DOCUMENTATION_INDEX.md for guidance
